# Clean Architecture

Source: *Clean Architecture: A Craftsman's Guide to Software Structure and Design* by Robert C. Martin.

## Processed Scope

### Chapter 7: SRP: The Single Responsibility Principle

Introduces [[single responsibility principle|Single Responsibility Principle]] as a module responsibility principle based on actor-owned change pressure rather than "one thing per module."

### Chapter 8: OCP: The Open-Closed Principle

Explains [[open closed principle|Open-Closed Principle]] as an architectural dependency rule: separate responsibilities by change pressure, then point dependencies toward higher-level policy so new behavior can be added with minimal modification to protected components.
